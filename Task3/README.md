# Задание 3. Технический радар и роадмап

Кейс «Будущее 2.0»: данные в DWH на SQL Server 2008, отчёты часами, впереди подключение фармацевтики и электроники. Задача - показать, как за год изменить технологический ландшафт под цели бизнеса.

| [02-roadmap.md](02-roadmap.md) | Каждый этап: работы, результаты, команды, ресурсы и обоснование через цели бизнеса |

Радар фиксирует движение за год: Yandex Cloud приходит сразу в Adopt, Lakehouse и Data Mesh идут с Trial на Adopt по итогам пилотов, semantic-слой и Terraform - из Assess в Trial, а SQL Server 2008, PowerBuilder, ESB Camel и Power BI поверх DWH переводятся в Hold с выводом.

Роадмап выстроен так, чтобы каждый следующий этап опирался на предыдущий: сначала общая платформа данных (этап 0), затем один живой домен для обкатки - финтех (этап 1), потом клиники с изоляцией медицинских данных (этап 2), поверх готовых витрин - портал самообслуживания (этап 3) и подключение партнёров с выводом DWH (этап 4).

Каждое перемещение технологии по кольцам сопровождается ADR, пересмотр радара - раз в полгода.
